PLC Configuration v1.13

Raspberry Pi Pico


Default PLC input behaviour is Active Low with the Pico's internal pull-up enabled and a 10 ms software debounce filter. A debounce value of 0 disables filtering.

I²C Bus Roles

Assign the Pico's two hardware I²C controllers to exclusive firmware roles.

Production configuration requires different hardware controllers and a complete SDA/SCL pin pair for each active role.

I²C I/O Expansion Devices

Enable each MCP23017 installed on the PLC I/O bus. The standard MCP23017 address range is shown below.

MCP23017 input pull-ups use the device's GPPU registers. Inputs default to Active Low with pull-ups enabled. The firmware uses mirrored open-drain MCP interrupts for immediate input refresh and also uses a staggered 5 ms background refresh as a fallback so the process image cannot go stale if an interrupt is missed.

Digital I/O Table

The Pico GPIO points are listed first. Enabled MCP23017 expansion points are added automatically below them. Choose the required function, enter a descriptor, then the point is automatically set to Enabled. Logical input and output numbers are assigned as persistent five-digit addresses such as I:00001 and O:00001. Free gaps are assigned before higher addresses, while an address retained by an existing physical point is never silently reassigned.

Logical PointPhysical ResourcePinFunctionDescriptorActive

For MCP23017 points, Function defaults to Output and Active defaults to Disabled. Physical input/output logical addresses use the lowest free number in their respective ranges; disabled points retain their assignments so existing ladder bindings cannot silently change meaning. Once a Function is selected and a Descriptor is present, Active is automatically set to Enabled. Ordinary Pico and MCP digital I/O descriptors automatically include the physical package pin number. Pico functions other than ordinary Input or Output use Logical Point n/a but may still be Enabled. Selecting an I²C, UART, or SPI function automatically configures the matching pin(s), fills each communication pin Descriptor with its selected function and physical Pico pin number, and disables alternate pin groups for the same peripheral until it is released.

Analog I/O

Analog I/O configuration is reserved in this version.

Pico ADC-capable GPIO and PWM-capable outputs will be organized here separately from ordinary digital I/O. Hardware selected on the Hardware tab will provide the available analog resources.

LCD Devices

Configure character LCDs connected through an I²C backpack. Each enabled LCD is assigned a persistent message selector register beginning at M:50001. The register stores the message index used by the LCD Message ladder block.

EnabledDevice NameI²C BusAddressDisplay SizeMessage Register

The selected display geometry determines which Flash message table the device uses. A 16×2 LCD can only index the 16×2 table; a 20×4 LCD can only index the 20×4 table.

Message Tables

Each message index represents one complete LCD screen. Message text is stored by display geometry so a message can never be rendered using the wrong width or number of lines. Line fields are limited to the configured LCD width.
