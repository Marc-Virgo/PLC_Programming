Digital I/O Table

The Pico GPIO points are listed first. Enabled MCP23017 expansion points are added automatically below them. Choose the required function, enter a descriptor, then the point is automatically set to Enabled. Logical input and output numbers are assigned sequentially as I: and O:.

Logical PointPhysical ResourcePinFunctionDescriptorActive

For MCP23017 points, Function defaults to Output and Active defaults to Disabled. Once a Function is selected and a Descriptor is present, Active is automatically set to Enabled. Pico functions other than ordinary Input or Output use Logical Point n/a but may still be Enabled. Selecting an I²C, UART, or SPI function automatically configures the matching pin(s), fills each communication pin Descriptor with its selected function and physical Pico pin number, and disables alternate pin groups for the same peripheral until it is released.

Analog I/O

Analog I/O configuration is reserved in this version.

Pico ADC-capable GPIO and PWM-capable outputs will be organized here separately from ordinary digital I/O. Hardware selected on the Hardware tab will provide the available analog resources.
