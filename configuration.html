Digital I/O Table

The Pico GPIO points are listed first. Enabled MCP23017 expansion points are added automatically below them. Choose the required function, enter a descriptor, then mark the point as Used. Logical input and output numbers are assigned sequentially as I: and O:.

Logical PointPhysical ResourcePinFunctionDescriptorActive

For MCP23017 points, Function defaults to Output and Active defaults to Not Used. A point cannot be marked Used until a descriptor has been entered. Pico functions other than ordinary Input or Output use Logical Point n/a but may still be marked Used.

Analog I/O

Analog I/O configuration is reserved in this version.

Pico ADC-capable GPIO and PWM-capable outputs will be organized here separately from ordinary digital I/O. Hardware selected on the Hardware tab will provide the available analog resources.
